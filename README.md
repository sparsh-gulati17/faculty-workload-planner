# Faculty Workload Planner

A simple university workload management system built using **HTML, CSS and JavaScript**.

### Features

- 👨‍🏫 **Faculty Management** – Add and manage faculty profiles, workload limits and eligible courses.
- 📚 **Course Management** – Register courses, semesters and weekly class requirements.
- 🔗 **Faculty-Course Linking** – Assign only eligible faculty to selected courses.
- 📅 **Timetable Planner** – Schedule 50-minute classes from Monday to Saturday.
- ⚖️ **Workload Allocation** – Track faculty capacity and course requirements.
- ⚠️ **Conflict Detection** – Prevent double-booking of faculty and semester slots.
- 📊 **Summary Reports** – Monitor scheduled classes, pending workload and faculty utilization.
- 💾 **Local Storage** – Save records in the browser using localStorage.

### Tech Stack

`HTML5` · `CSS3` · `JavaScript`
